# AGENTS.md — {{TOPIC}} 知识库

> 智能体开机读物。任何 agent 把本知识库作为工作空间打开时，先读这个文件。

## 这是什么库

围绕「{{TOPIC}}」构建的个人知识库，基于 llm-wiki 方法论：知识编译一次、持续维护，而不是每次提问都从原始素材重新推导。创建于 {{DATE}}。

## 必读文件（涉及具体问题前先读）

1. `index.md` — 全库地图：页面数量、分类导航、待办。**页面数量等快变数据以这里为准，本文件不记。**
2. `purpose.md` — 研究目标、关键问题、范围边界。
3. `.wiki-schema.md` — 语言、别名词表、关系词汇表等配置。

## 目录职责

| 位置 | 内容 | 谁维护 |
|---|---|---|
| `raw/` | 原始素材（不可变留档，按来源分子目录） | AI（llm-wiki 工作流） |
| `wiki/entities/` | 实体页（概念、人物、工具等） | AI |
| `wiki/topics/` | 主题页 | AI |
| `wiki/sources/` | 素材摘要 | AI |
| `wiki/comparisons/` | 对比分析 | AI |
| `wiki/synthesis/` | 综合分析与对话结晶 | AI |
| `wiki/queries/` | 保存的查询结果 | AI |

用户自建的应用层目录（题库、学生档案等）如有，请在本表下方自行补充。

## 铁律

1. 回答本库主题相关的问题，必须基于本库页面，不要凭模型记忆——具体事实容易答错。
2. 新页面用 `[[双向链接]]` 关联已有页面，并同步更新 `index.md` 和 `log.md`。
3. 消化素材时遵守置信度标注（EXTRACTED / INFERRED / AMBIGUOUS / UNVERIFIED）。
4. 消化、查询、深度报告、图谱等操作走 llm-wiki skill 的工作流（init / ingest / query / digest / lint / status / graph）。

## 维护本文件

本文件只写**慢变事实**（身份、规则、目录职责）。目录结构或使用规则变化时，顺手更新对应段落；页面数量等快变数据永远不写进这里。
